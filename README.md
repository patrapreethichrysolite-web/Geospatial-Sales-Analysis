Geospatial Sales Analysis 

 Project Overview
This project analyzes sales data across different states and cities to identify high-demand regions and recommend potential locations for business expansion.

Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Dashboard Design

 Analysis Performed
- State-wise Sales Analysis
- Top 10 Cities by Sales
- Region-wise Sales Distribution
- Category-wise Sales Analysis
- New Store Location Recommendations

Key Insights
- High-performing states were identified.
- Top revenue-generating cities were analyzed.
- Three potential locations were recommended for expansion.
  
Recommended Store Locations:
1. California
2. Texas
3. Washington
